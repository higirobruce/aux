03 · What's next

Recommended next move

Pick one

Of the four open v0.3 lanes (3 plugins, Stem timeline, Smart EQ panel, Reference Rooms, Clip editing), the highest-leverage next step is the read-only Stem timeline — it unlocks Clip editing v1 downstream, and it's the only v0.3 feature that meaningfully changes how the mixer looks. The plugin marathon is faster but boring; doing timeline now means clip editing is reachable inside v0.3.

Option A — Stem timeline (recommended)

Read-only horizontal lane per stem. Waveform render via OfflineAudioContext + downsampled peaks, transport-synced playhead, click-to-jump, in/out markers. Mirrors mute/solo from the channel strip.

Cost: ~1 medium slice. Touches the mixer shell layout (third row above the console), a new _timeline.tsx, and a small peaks worker. No DSP, no MixState change.

Unlocks: Clip editing v1 has somewhere to live.

Option B — Finish the plugin suite

Three plugins to go: Tape (easy — single-stage saturation curve), Console (medium — channel-style nonlinear coloration), MB-Comp (heavy — 3 or 4 bands × compressor + Linkwitz-Riley crossovers).

Cost: 3 slices, ~one each. The pattern is by-rote at this point; the work is in tuning DSP not wiring it up.

Unlocks: Closes "all 12 native plugins" on the v0.3 checklist.

Option C — Smart EQ panel

Polish the EQ-8 surface. Curve display, frequency-response plot, draggable band nodes, expose all 8 bands (today only Lo / Mid / Hi are surfaced on the channel strip).

Cost: Larger than the plugin slices because the interaction model is bespoke (drag points on a canvas, frequency-log axis). DSP is already done.

Option D — Reference Rooms

A small set of EQ presets (laptop, earbuds, car, club) applied to the Master, switchable from the Master strip. Spot-check translation mid-mix.

Cost: Smallest of the four. One worklet (or even just a few cascaded biquads in the existing chain), one toggle group on the Master strip, a tiny MixState bump.
